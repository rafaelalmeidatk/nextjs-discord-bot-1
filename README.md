# Next.js Discord Bot

The source code of the Discord bot for the official [Next.js Discord](https://nextjs.org/discord).

## Features

- Adding users to certain channels based on message reactions
- Anti-spam protection through a whitelist
- Monitoring for certain emojis and words
- Helping log messages that mods flag
- Keeping rules up to date
- Alert reactions
- Honeypot channel (bans members (bots) who post in the designated channel)
- Checking that new showcases are Next.js apps and flagging the rest for moderators
- "Reply with issue" context menu for sending helpful pre-written replies, with optional mod actions
